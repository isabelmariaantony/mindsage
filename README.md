# MindSage: Dementia Care App

MindSage is a web application designed to assist in detecting dementia and offering personalized care advice. The app uses MRI image classification with a machine learning model, FAISS for document retrieval, and OpenAI GPT-3.5 to provide tailored advice based on user profiles and their preferences.

## Features

1. **User Authentication**: Users can sign up, log in, and log out. Authentication is handled securely with hashed passwords.
2. **Profile Setup**: Users can set up or modify their profile, including age, location, medical details, eating habits, lifestyle details, and specific dementia care preferences.
3. **MRI Scan Upload**: Experts can upload MRI images to classify the stage of dementia (No dementia, Very mild, Mild, Moderate).
4. **Query for Care Advice**: Based on the user profile, preferences, and the dementia classification, users can ask for personalized dementia care tips and receive responses generated by OpenAI GPT-3.5.
5. **Document Search with FAISS**: The app retrieves relevant documents using FAISS (an in-memory document index) for generating GPT-based responses.
6. **Session-based Authentication**: After logging in, the app dynamically displays different tabs for profile setup, MRI upload, and care advice.

## Installation

To run the MindSage app locally, follow these instructions:

### Prerequisites
- Python 3.9 or later
- Install [pip](https://pip.pypa.io/en/stable/)

### Clone the Repository

```bash
git clone https://github.com/yourusername/mindsage.git
cd mindsage
```

### Create a Virtual Environment

Set up a virtual environment to manage dependencies:

```bash
python3 -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
```

### Install Dependencies

Install the required dependencies using `pip`:

```bash
pip install -r requirements.txt
```

Make sure to have **NumPy 1.25.0** or below as one of the dependencies.

### Environment Variables

Set up environment variables by creating a `.env` file in the project directory. The `.env` file should look like this:

```bash
OPENAI_API_KEY=<your_openai_api_key>
```

Replace `<your_openai_api_key>` with your actual OpenAI API key.

### Initialize the Database

Run the following command to initialize the SQLite database:

```bash
python3 initialize_db.py
```

This will set up the user and document storage tables.

---

## Running the App

Run the Streamlit app using:

```bash
streamlit run app.py
```

This will start the Streamlit web app, and you can access it at `http://localhost:8501` in your browser.

## Usage

### Signup and Login Functionality

MindSage includes a simple user authentication system. Users must either **sign up** or **log in** to access the app's features.

1. **Signup**:
   - Navigate to the **Signup** option.
   - Enter a unique username and password. The password is securely hashed using bcrypt and stored in the SQLite database.
   - Once signed up, you can proceed to log in.

2. **Login**:
   - Navigate to the **Login** option.
   - Enter your username and password to authenticate. If the credentials match, you will be logged in and granted access to the app's features.
   
3. **Session**:
   - After logging in, the user remains authenticated for the duration of the session.
   - The app dynamically displays tabs for profile setup, MRI upload, and getting care advice.
   
4. **Logout**:
   - Users can log out by clicking the **Logout** button next to the welcome message. This will clear the session and return the user to the login screen.

### Tabs in the App

1. **Profile Setup**:
   - Enter your name and set up your profile with age, location, medical details, eating habits, lifestyle, and any specific dementia care challenges.
   - You can update the profile any time by modifying the fields and clicking the "Update Profile" button.

2. **Detect Dementia (MRI Upload)**:
   - Upload an MRI image (JPEG, JPG, or PNG).
   - The image is processed to classify dementia into one of the categories: No dementia, Very mild dementia, Mild dementia, Moderate dementia.
   - The classification is stored in the database and displayed in the profile.

3. **Get Care**:
   - Ask dementia care-related questions based on your profile and preferences.
   - The system retrieves relevant documents from the FAISS index and combines them with GPT-3.5 for personalized advice.
   - The last query you made is saved and displayed for reference.

### Logout
You can log out by clicking the **Logout** button next to the welcome message.
